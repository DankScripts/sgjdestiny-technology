# Destiny shuttle

The shuttle provides a fixed route between Destiny and Eden; it is not a free-flight vehicle. Eden has no Stargate. Players aboard can travel together.

1. Board the shuttle and right-click the pilot seat. Other players may use the passenger seats or stand aboard.
2. While seated as pilot, use the cockpit helm to open shuttle navigation.
3. Choose **Launch to Eden** or **Launch to Destiny**, as shown on the screen. Stay aboard until arrival.

The first trip to Eden may take extra time while the server searches for and prepares a natural landing berth. The search looks 2,500–5,000 blocks from Eden's obelisk; if it cannot find a suitable site, the pilot sees an error. The return route needs a valid Destiny departure shuttle.

{: .note }
Operators can link a berth manually with `/sgjdestiny shuttle linkBerth` while seated in that shuttle's pilot seat. An Eden berth must be 2,500–5,000 blocks from the obelisk. This is an administrative recovery option, not a required step for normal travel.
