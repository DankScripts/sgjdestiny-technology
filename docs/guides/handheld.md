# Handheld Controller

The Destiny Kino Remote combines gate dialing and Kino control in a single handheld interface.

## Opening the interface

Use the remote to open its interface. While it is open:

- The **GATE** side button shows gate controls.
- The **KINO** side button shows Kino controls.
- The bottom side button goes back or closes the interface.

Sneak-use with the interface closed changes which page opens on the next normal use; it does not switch an open screen. On NeoForge, if the remote opened directly to Kino control, its gate list is empty even after selecting **GATE**. Close it and check the remote's tooltip. If it is in Kino Control mode, sneak-use it to select gate mode, then use it normally again. A usable gate or DHD is still needed to load the list.

Deploying, flying, and recalling a Kino do not require a nearby gate; a deployed Kino keeps its own chunk loaded as it travels.

## Remote gate dialing

The remote can dial through a usable registered Universe gate in the player's current dimension without a nearby console or a fixed distance limit. A nearby Universe DHD may be selected first; otherwise the remote looks for the nearest usable registered Universe gate. This allows a player on a destination planet to dial home. Destiny itself has a normal seven-symbol destination entry in addition to its special nine-symbol programmed address.

When the gate is idle, clicking a destination in the handheld list begins dialing immediately. The stationary console uses a separate selection and **Select** step. The remote temporarily keeps the gate's chunk ticking while its direct dialing sequence completes. If no usable gate is found, check the message shown in game.

## Kino controls

The Kino page provides **Deploy/Follow**, **Hold**, **Recall**, directional movement, vertical movement, telemetry scanning, and live video. The player must hold the remote for flight commands to be accepted.
