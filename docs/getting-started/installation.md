# Installation

## Requirements

| Component | Required version |
|:--|:--|
| Minecraft | 1.20.1 |
| Forge | 47.4.0 or newer compatible 47.x build |
| Stargate Journey | 0.6.48 or newer |
| Immersive Portals | 3.0.7 for Forge 1.20.1 |
| Cloth Config | Version required by Immersive Portals |

Stargate Journey: Deco 1.2.0 or newer is optional. The addon detects its Destiny Bearing when installed. Distant Horizons is also optional.

## Client and server

Install SGJourney Destiny DHD and every required dependency in the `mods` folder on both the server and every connecting client. The Immersive Portals dependency provides the Kino's full-quality remote world view.

1. Stop Minecraft or the server.
2. Remove older `sgjdestiny-dhd` jars from the `mods` folder.
3. Add the current addon jar and required dependencies.
4. Start the game and confirm the addon appears in the Mods screen.

{: .warning }
Do not keep multiple versions of this addon in the same `mods` folder.
