# Stargate Journey: Destiny Technology

Stargate Journey: Destiny Technology is a Forge 1.20.1 addon for **Stargate Journey** that recreates Destiny's dialing systems, shipboard effects, handheld controller, and Kino probes from *Stargate Universe*.

![Destiny gate room](assets/images/destiny-gate-room.png)

Use this documentation to install the addon, build and operate the Destiny equipment, dial seven- and nine-symbol addresses, deploy a Kino, view its live feed, and configure the mod for a multiplayer server.
