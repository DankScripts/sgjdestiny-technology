# Quick Start

1. Build or locate a Stargate Journey Universe Stargate.
2. Place the **Destiny DHD** close enough to link with the gate.
3. Place the **Destiny Bearing** at the gate and a horizontal **Universe Stargate Chevron** in the floor directly in front of it.
4. Place **Destiny Floor Vents** in the gate room with each grate facing the intended steam direction.
5. Use the console to select a known destination and start dialing.
6. Craft a **Destiny Kino Remote** and **Kino** for remote exploration.

The floor chevron illuminates after the final chevron locks and the connection succeeds. It remains lit while the wormhole is open. Steam vents discharge shortly after the gate completes shutdown.
