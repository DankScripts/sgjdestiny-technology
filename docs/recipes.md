# Recipes

Each row describes the three crafting-grid rows from top to bottom.

## Destiny DHD

`AGA / IRI / ANA`

- `A`: Naquadah Alloy ingot
- `G`: Black glass pane
- `I`: Iron ingot
- `R`: Comparator
- `N`: Pure Naquadah

### Crystallizer alternative

The Stargate Journey Crystallizer can also produce a Destiny DHD from:

- 1 Comparator as the crystal base
- 2 Iron Ingots as the primary ingredient
- 4 Naquadah-Iron Alloy as the secondary ingredient
- 1,000 mB Liquid Naquadah

## Destiny Floor Vent

`III / BBB / III` produces four vents.

- `I`: Iron ingot
- `B`: Iron bars

## Kino Remote

`CBC / RGR / CBC`

- `C`: Copper ingot
- `B`: Blackstone
- `R`: Redstone
- `G`: Tinted glass

## Kino

` G  / GEG /  C `

- `G`: Glass
- `E`: Eye of Ender
- `C`: Copper ingot

## Earth Gate Designator

`CBC / RER / CBC`

- `C`: Copper ingot
- `B`: Blackstone
- `R`: Redstone
- `E`: Stargate Journey Communication Crystal

## Destiny Oxygen Tank

`CIC / CGC / CIC`

- `C`: Copper ingot
- `I`: Iron ingot
- `G`: Glass bottle

## Destiny Environmental Suit

| Piece | Pattern | Materials |
|:--|:--|:--|
| Helmet | `III / IGI / C C` | Iron ingots, tinted glass, copper ingots |
| Chestplate | `I I / ITI / III` | Iron ingots and a Destiny Oxygen Tank |
| Leggings | `III / I I / C C` | Iron and copper ingots |
| Boots | `I I / C C` | Iron and copper ingots |

JEI remains the easiest way to view the exact shaped grid in game.
